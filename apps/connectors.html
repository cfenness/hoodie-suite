Kroger

APIcreds needed
Official Kroger Developer API — store-level price + inventory status (HIGH / LOW / OUT) with the bottle-shot image. Create an app at developer.kroger.com (scope product.compact); the Client ID/Secret are on My Apps → your app.
The Kroger API is search-based, so coverage = terms × store regions — neither is optional, but leave them blank for the full built-in coverage (all banners, whole taxonomy). Narrow them only for a quick check. Creds are used for this run and cached in memory. For the daily scheduler, set them once: flyctl secrets set KROGER_CLIENT_ID=… KROGER_CLIENT_SECRET=…
