Pipeline stages

Where the data is, how much is waiting, and whether the number can be trusted. Every figure is measured from the warehouse — nothing here is modelled.

Reading the warehouse…

A dash is not a zero. Where a count could not be computed the cell shows —, not 0. Row counts read Parquet footers, so an unreadable table will happily report millions; showing it as zero would state a falsehood with total confidence.

Idle is not stalled. idle means nothing is waiting — success with no work. waiting is a real backlog, stalled is one that has stopped moving, and never means the table is declared but nothing ever landed. Collapsing those is what let a daily source report benignly while landing nothing for weeks.
